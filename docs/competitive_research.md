# Competitive Research Notes

## Challenge Signals

The Band of Agents Hackathon rewards practical enterprise workflows where agents communicate, coordinate, exchange context, and complete work together. The strongest fit is not a single assistant with helper prompts. The workflow must show Band as the collaboration layer with visible handoffs, shared context, task state, role specialization, and review/decision-making.

Primary source: https://lablab.ai/ai-hackathons/band-of-agents-hackathon

## Why Procurement Still Works

Procurement is named in the challenge examples and has a natural enterprise collaboration structure:

- requester and procurement coordination;
- vendor diligence;
- finance/ROI;
- security and compliance;
- legal and policy;
- human approval.

This is a strong business-value story because slow vendor approval directly affects revenue, risk, and operational speed.

## Similar Submission Risk

Live review on June 13, 2026 found at least one submitted concept in the same neighborhood: GateKeeper, a vendor risk approval workflow. That means ProcureGuard should not pitch itself only as "agents approve vendors." The stronger pitch is:

- an enterprise approval room;
- a shared context steward;
- adversarial red-team review before decision;
- human signoff routing;
- tamper-evident audit sealing;
- downloadable approval record;
- custom case replay for judge-entered scenarios;
- fast demo mode for reliable evaluation;
- documented live Band Remote Agent path.

## Differentiators To Emphasize

1. **Red Team Auditor**
   - Challenges the shared context before approval.
   - Routes warnings back to Security and Legal.
   - Prevents the workflow from looking like a linear automation.

2. **Evidence Clerk**
   - Converts parallel specialist artifacts into a shared packet.
   - Separates consensus, unresolved questions, readiness, and state.
   - Makes context exchange visible and central.

3. **Audit Seal**
   - Creates a SHA-256 digest across case, artifacts, context, challenge, decision, gate, and timeline.
   - Gives the demo a concrete governance artifact.

4. **Cross-Framework Story**
   - Each role declares a framework/runtime profile.
   - Band becomes the common room connecting those different profiles.

5. **AI/ML API Prize Fit**
   - AI/ML API powers structured reasoning, extraction, summarization, challenge review, and decision memo generation.
   - Deterministic fallback keeps the demo reliable without hiding the live provider path.

6. **Judge Replay**
   - Judges can run a new vendor case, inspect the routed handoff graph, download the report, and download the evidence bundle.
   - This makes the project feel like a working enterprise review product, not only a prepared video.

## Submission Pitch

ProcureGuard AI is not a chatbot for procurement and not just a vendor-risk scorer. It is a multi-agent enterprise governance room where specialists use Band to hand off structured context, challenge unsafe assumptions, route decisions to humans, and produce a replayable, tamper-evident approval record.
